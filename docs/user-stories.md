# User Stories

## Registration

As a user

I want to create an account

So that I can access MusiqSphere.

---

## Streaming

As a user

I want to stream songs

So that I can listen online.

---

## Download

As a user

I want to download songs

So that I can listen offline.

---

## Playlist

As a user

I want to create playlists

So that I can organize music.

---

## Favorites

As a user

I want to like songs

So that I can access them quickly.

---

## Global Discovery

As a user
I want to browse music from other users in the Global Explorer
So that I can find new tracks to add to my collection.

---

## Personal Collection

As a user
I want to "Clone" a song from the Global Explorer into my library
So that I can have it in my dashboard and edit its details (Title/Artist) to my liking without affecting others.

---

## Library Management

As a user
I want to edit the metadata of my uploaded songs or delete them from the cloud
So that I can correct mistakes or remove tracks I no longer want to share.

---

## Offline First

As a user
I want the website to load even when I have no internet
So that I can still browse and play my downloaded music.
