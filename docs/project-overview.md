# MusiqSphere

## Tagline

Your Music Universe

## Overview

MusiqSphere is a cross-platform music streaming application that enables users to stream and download music across Android, iOS, and Web platforms.

Users can:

- Stream music online
- Download music for offline playback
- Create and manage playlists
- Like and favorite songs
- Search songs, artists, and albums
- Access their music library from multiple devices

## Supported Platforms

- Android
- iOS
- Web Browser
